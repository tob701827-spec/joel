1. Introducción

El video explica qué es Supabase, una alternativa open source a Firebase que nos permite crear un backend completo sin programar tanto. Muestra cómo crear un proyecto, configurar la base de datos Postgres, activar la API REST automática y conectar una app con autenticación.

2. Conceptos Fundamentales

1. Supabase

Plataforma BaaS (Backend as a Service) que ofrece base de datos, auth, storage y API automática.

2. PostgreSQL

Base de datos relacional potente que usa Supabase por defecto. Guarda tablas con filas y columnas.

3. REST API

Supabase genera automáticamente una API para que tu web pueda hacer GET, POST, PUT, DELETE sin crear servidor.

4. RLS (Row Level Security)

Sistema de seguridad para decidir qué usuario puede ver o editar qué filas.

5. Autenticación

Login con email/contraseña, Google, etc. Supabase maneja usuarios en la tabla auth.users

3. Cuestionario Resuelto (12 preguntas)

1. ¿Cuál es el tema principal del video? Explica de qué trata.

El tema principal es Supabase como herramienta para crear un backend completo rápidamente. El video hace un overview práctico: crear proyecto, crear tablas, ver cómo se genera la API REST, y cómo conectarlo desde el frontend con JavaScript.

2. ¿Qué problema o necesidad tecnológica se aborda?

Resuelve el problema de tener que programar todo un servidor desde cero. Muchos estudiantes no saben Node/Express. Supabase evita eso y te da base de datos, API y login listo para usar en minutos.

3. ¿Cuáles son los cinco conceptos más importantes? Define cada uno.

  • Backend as a Service: No haces servidor, usas uno ya hecho.
  • PostgreSQL: Base de datos SQL avanzada.
  • API REST automática: Cada tabla se convierte en una URL tipo /rest/v1/tabla
  • RLS - Row Level Security: Reglas de seguridad por fila.
  • Supabase Client: Librería JS para conectar tu web con supabase.

4. ¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Supabase Dashboard (para crear tablas), PostgreSQL (BD), JavaScript SDK, SQL Editor, Authentication, Storage para archivos, y Postman para probar la API.

5. ¿Qué procedimientos o pasos se explican? Preséntalos en orden.

  1. Crear cuenta en supabase.com y nuevo proyecto.
  2. Crear tabla desde Table Editor.
  3. Activar RLS y crear policies.
  4. Copiar URL y ANON KEY.
  5. Instalar supabase-js y conectar: createClient(url, key).
  6. Hacer consultas: select, insert, update, delete.

6. ¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

El ejemplo principal es crear una tabla de recetas. Se crea tabla con id, nombre, ingredientes. Luego desde JS se hace supabase.from('recetas').select() y muestra los datos en la web. Si RLS está desactivado no funciona, por eso enseña a activarlo.

7. ¿Qué conocimientos previos son necesarios para comprender lo explicado?

Básico de HTML, JavaScript, qué es una base de datos, qué es una tabla, y nociones de API (GET/POST).

8. ¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Es gratis para empezar, es muy rápido, no necesitas servidor, es open source, tiene documentación buena y escala bien. Ideal para proyectos del colegio.

9. ¿Qué dificultades, errores o precauciones deben considerarse?

Si olvidas activar RLS quedas inseguro. Si no pones policies, no podrás leer datos y parecerá que está roto. Cuidar no exponer la Service Role Key. Verificar el email de usuarios.

10. ¿Cómo aplicarías lo aprendido en un proyecto informático real?

Lo usaría para mi proyecto final, una app de comunicación para el colegio. cada estudiante tendria que poner una identificación para poder acceder a una cuenta, de igual manera también los profesores

11. ¿Qué parte del video consideras más importante y por qué?

La parte de RLS. Porque sin eso la base de datos queda abierta y es un error de seguridad muy común.(Ya voy a arreglar esa parte profe:c)

12. ¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Aprendí que no hace falta crear una API a mano, Supabase la crea sola. Se lo explicaría a un amigo asi "Es como Firebase pero con Postgres, creas tu tabla en la web y ya podes pedir datos con una línea de JS".

4. Aplicación Práctica

Ejemplo de conexión real:

import { createClient } from '@supabase/supabase-js'
const supabase = createClient('TU_URL', 'TU_ANON_KEY')

// Leer datos
const { data } = await supabase.from('productos').select('*')
console.log(data)

// Insertar
await supabase.from('productos').insert({ nombre: 'Laptop', precio: 500 })
